# 三个数据源对照

拿到股市数据的路径只有三条，各自能给的东西**不重叠**，必须分清。

## 总览

| 维度 | A. 公开 API | B. 客户端 GUI | C. 聊天消息 |
| --- | --- | --- | --- |
| 地址 / 入口 | `https://tool.myflycat.cn/quant/api/*`（BCquant；旧 `pleasance.icu` 只作历史样本来源）| 游戏内 `/invest` 容器 | 服务器聊天栏 |
| 鉴权 | 无，免鉴权 GET | 需要账号 + 白名单 + 在线 | 同 B |
| 粒度 | 15 分钟采样 | 当前瞬时值 | 事件触发 |
| 历史 | **有**，可回溯到 2026-07-09 | 无，只有当前 | 无 |
| 破产公司 | **有**（2026-09-26 快照 38 家；2026-09-28 已变 43 家）| 有：首屏 16 家里也含已破产行（单价 0.00 / 历史总涨跌 ↓100.00%）| 破产瞬间有通知 |
| 个人持仓 / 资产 | **完全没有** | **只有这里能读** | 无 |
| 市场总览指标 | 有（/api/overview）| 无 | 无 |
| 稳定性 | 第三方站点，非官方承诺 | 官方界面，稳 | 广播会漏发（主触发 + 兜底）|
| 离线可用 | 是（本机 curl 即可）| 否 | 否 |
| 样例文件 | 未随仓库发布 | 未随仓库发布 | 未随仓库发布 |

## A. 公开 API（BCquant，`https://tool.myflycat.cn/quant`）

> base 可在 `config/bcstock.json` 的 `api.base` 或 `-Dbcstock.api.base` 覆盖；代码默认值见 `ApiClient.java:32`。

**能给**

- 全市场 54 家公司的实时价、涨跌幅、风险度、状态、剩余股数（`/api/companies`）
- 每家公司的 K 线时间序列，15m/1h/4h/24h 四档：`/api/history/candles?company_id={id}&interval=15m[&limit=N]`，
  返回键是 `candles`（旧 `/api/kline/{id}` 在本 base **404**）
- 剩余可售股数：随 `/api/companies` 的 `available_shares` 返回（**当前值，不提供时间序列**）
- 全市场广度、今日/昨日售出回购流量、小时分布、最近事件（`/api/overview`）
- 单家公司统计：最高/最低/均价/样本数（`/api/company/{id}`——**本 base 404，未使用**，见 `api-reference.md`）

**给不了**

- 任何与"我"相关的数据：我的持仓、我的成本、我的现金、我的可买额度
- 比 15 分钟更细的价格
- ~~前端展示价与成交价的差异（未验证）~~ **已实测**：盘中牌价 ≠ `/invest company info` 的实时价
  （一笔：98.49 → 105.26，差 6.77 ≈ 6.87%）→ **下单按实时价**，卖出不再另扣税

**注意**：这套接口是从站点前端页面里解析出来的，站点没有公开 OpenAPI，也没有承诺稳定性。
**挂了就没了**。用它就要做好降级准备。

## B. 客户端 GUI（/invest）

**能给**

- 个人持仓：投资公司数、总持股数、资产总价值（`您的投资组合` 容器）
- 在售 16 家的当前价 / 涨跌幅 / 风险度 / 市值 / 历史总涨跌 / 购买档位
- 通知开关状态

**给不了**

- 历史序列
- 破产公司的**历史序列**（聊天里只能看到它当前 0.00 的价与破产通知）

**关键**：个人数据（持仓、资产）**只有这条路径**。公开 API 里 `latest_cash_at` 停在
`2026-07-08`，说明个人资金那条数据线早就断了。任何涉及"我该买多少 / 我赚了多少"的功能，
都必须走客户端。

## C. 聊天消息

已知会出现的：

- `帕拉伦股市 > 所有商业股票已更新。`（价格刷新时）
- 破产相关通知（通知设置里叫「公司破产」）
- 大乐透、Crates 等无关系统的消息会混在同一栏

**用法**：这条广播是客户端行情刷新的**主触发**（认到后发 `/invest companies` 增量叠加）。
它**会漏发**：本次采集中价格在 01:48 确实跳了，但完整日志（01:51:46–02:02:18）里
**没有**出现「已更新」这行。所以超过 20 分钟没刷成功要回 API 兜底，不能只信聊天。

## 选型结论

| 需求 | 该走哪条 |
| --- | --- |
| 行情、K 线、历史回测 | A（进服全量 + 20 分钟漏发兜底） |
| 我的持仓、成本、该卖多少 | B / 聊天命令 `portfolio` |
| 价格刚刷新 | C 广播主触发，叠加 `/invest companies`；漏了走 A |

如果最终做游戏内 mod：A 负责看盘与信号，B 负责账户。**两者不能互相替代。**
