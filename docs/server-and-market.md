## 价格刷新节律（实测，硬证据）

从帕拉伦联合储蓄的 K 线样本（7513 根）反推：

```
近 8 个采样点：00:03:04  00:18:08  00:33:06  00:48:05
               01:03:05  01:18:06  01:33:04  01:48:04
相邻间隔（分钟）：15.06  14.97  14.97  15.00  15.01  14.97  14.99
全长 7513 条，间隔中位数 15.00 分钟
```

结论：

- 刷新周期 **15 分钟**，相位固定在每 15 分钟的 **:03 / :18 / :33 / :48**
- 每个采样点是**单点价格**（OHLC 多数完全相同），不是真正的 OHLC 聚合
- 序列里存在一段 793 分钟的空档（服务器停机或采集器掉线），做回测时要处理

推论（对开发重要）：既然刷新是 15 分钟一跳，**盘面/ API 的展示价是同一份数据、同一个粒度**，
抓包 / 逆协议拿不到"更细"的价格。要更细只能靠客户端在 :03:04 那一瞬间抢读，收益有限。

⚠️ **但有一个例外，且直接关系下单**：`/invest company info` 给的是**实时价**，与展示价不是同一口径。
实测一笔：牌价 98.49 → 实时 105.26，中间多出 6.77（≈6.87%）。（`ui/LiveQuoteFlow.java`；
测试 `ui/TradeDraftTest` / `ui/TradeFlowTest`；回执样本见 `docs/commands.md` §10。）
**结论：下单前必须取实时价，不能用盘面价当成交价。**
