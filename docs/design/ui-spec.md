| 4 | ~~**文字一律不带阴影**：`drawString(..., hasShadow = false)`~~ → **修订（2026-09-27）**：自绘文字仍 `hasShadow = false`；原版控件文字阴影随控件 | 同上 |
| 5 | ~~深色底 + 单一强调色~~ → **修订（2026-09-27，一凡拍板：UI 全面倒向原版观感）**：自绘文本用原版 16 色；`GOLD` **仅** K 线折线与 HUD 倒计时警示。涨绿/跌红仍是语义色 | 设计方向变更，非 bug 修复 |

- 界面文字不许出现指令名 / 按键别名 / JVM 参数名
- 渲染路径零发包、零发网

## 4. 栅格与布局算法

**核心规则（修订 2026-09-27，一凡拍板）：**

- ~~代码里禁止出现魔法数字坐标（必须由 `BoardLayout` 的函数算出）~~
- **自绘部分**不许魔法数字坐标（必须由布局常量 / 布局函数推导）；
- **使用原版控件时**坐标必须由布局常量或控件 API（`Entry.getContentX()` 等）推导，不许在业务逻辑里散落字面量。

```
CELL        = 18                    // 单元格高，同原版
PAD_X       = 12                    // 表格左右内边距
TOP_BAR_H   = 24
HEADER_H    = 16
BOTTOM_BAR_H= 24

originX()   = (width - columnWidthSum()) / 2      // 整块永远水平居中
tableTop()  = TOP_BAR_H + 8
rowsTop()   = tableTop() + HEADER_H
rowY(row)   = rowsTop() + row * CELL
visibleRows()= max(1, (height - rowsTop() - BOTTOM_BAR_H) / CELL)
```

### 列定义

| 列 | 内容 | 宽度 | 对齐 |
| --- | --- | --- | --- |
| 1 | 公司名（买/卖建议加前缀，观望不加字） | 100 | 左 |
| 2 | 单价 | 60 | 右 |
| 3 | 涨跌 | 56 | 右 |
| 4 | 风险 | 32 | 右 |
| 5 | 持仓 | 48 | 右 |
| 6 | 成本 | 56 | 右 |
| 7 | 盈亏 | 56 | 右 |
| 8 | 操作（买/卖按钮） | 72 | 中 |

`columnWidthSum() = 100+60+56+32+48+56+56+72 = 480`（列间距已含在宽度里）。
`UiPalette.TABLE_W = 480`。

**C1 建议（不加新列）**：`DecisionEngine` 用当前 `decision.preset` 门槛出买/卖/观望。
盘面公司名前缀 `买 `（`UP`）/ `卖 `（`DOWN`）；观望不加字。查找名仍是公司名。
买入数量弹窗自定义框预填该档 `defaultBuyQty`。不发命令。
窗口宽度 < 480 + 2*PAD_X 时：**降级为窄模式**，砍掉「涨跌 / 风险 / 成本 / 盈亏」，
**保留「操作」列**（买卖是核心功能），底栏提示
`窗口过窄，已隐藏 涨跌/风险/成本/盈亏`。不许把文字画出屏幕。

操作列按钮矩形必须由 `BoardColumns.contentColumnX(contentX, ACTION)` + `UiPalette` 常量算出，禁止魔法坐标
（原 `BoardLayout` 已删，见 `docs/evidence/track-b/b5-vanilla-widgets-offline.md`）。

## 6. 交互清单

| 输入 | 行为 |
| --- | --- |
| 滚轮上下 | 视窗滚动 1 行；到顶/底不再滚（不许滚出空白） |
| ↑ / ↓ | 移动选中行；到顶/底停住 |
| PageUp / PageDown | 翻一屏 |
| 鼠标移动 | 更新 hover 行 |
| 左键点行（非按钮区） | 选中该行并显示原版白框（`Entry.mouseClicked` 返回 true → 列表 `setFocused`→`setSelected`） |
| 左键点「买」 | 数量弹窗（买档）；**不改选中态**（按钮吃点击后对列表返回 false，避免抢选中） |
| 左键点「卖」 | 数量弹窗（卖档，含全部抛出）；无持仓时灰显无反应；**不改选中态**（同上） |
| Enter | ~~展开/收起详情浮层~~ → **打开详情屏**；确认框打开时 = 确认下单 |
| `S` | 切换排序（默认 → 涨跌 → 风险 → 盈亏） |
| `F` | 切换筛选（全部 → 只看持有 → 排除破产） |
| Esc | 详情屏 → **返回列表（复用实例，选中/滚动不丢）**；确认框 / 数量弹窗取消；列表上则关界面 |
| 键盘焦点 | 界面上**不显示任何"按键绑定名"**之类的技术细节（一凡 UI 规约：不用指令名/别名） |

**已废弃（2026-09-27）**：右键 / Shift+左键 / Shift+右键 下单快捷键（改行内按钮）。

**红线**：`trade.enabled=false` 时，所有买卖入口**灰显且点击无任何反应**（不是弹提示，是没反应）。

## 7. 数值显示规则

| 数据 | 规则 | 例 |
| --- | --- | --- |
| 单价 | `1.30 K` → **真实值**两位小数；≥ 1e6 加千分位 | `1.30 K` → `1300.00`；`2.78 M` → `2,780,000.00` |
| 市值 | 保留原始缩写，**同时**给换算值 | `4.72 M (4,720,000.00)` |
| 涨跌 | 箭头转正负号，保留两位 | `↑ 1.82%` → `+1.82%` |
| 破产 | 单价列显示 `已破产`，整行 `MUTED`，涨跌显示 `-` | — |
| 持仓为 0 | 持仓 `-`、成本 `-`、盈亏 `-`（**不显示 0.00**） | 免得和"真的赚了 0"混淆 |
| 未知值 | 一律 `--`，**不许显示 0** | 数据没到 ≠ 值是 0 |
